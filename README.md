## ✨ Sobre el projecte

Un lloc web estàtic en català inspirat en l'univers d'**Eternal Sunshine** i la idea d'una gira d'Ariana Grande. Hi trobaràs informació del tour, una galeria, preguntes freqüents i pàgines de contacte i registre.

> Projecte de fans, no oficial ni afiliat a Ariana Grande.

## 💖 Què hi trobaràs?

- **Inici** amb presentació del tour, dates i sponsors.
- **Galeria** d'imatges.
- **FAQ** amb preguntes freqüents.
- **Contacte** i **registre**.
- Pàgines de **privadesa**, **cookies** i **termes i condicions**.
- Disseny responsive amb estils propis i petites interaccions en JavaScript.

## 🌷 Fet amb

- HTML
- CSS
- JavaScript
- Firebase Hosting (configurat a `firebase.json`)

## 🚀 Com veure'l en local

Com que és un lloc estàtic, pots obrir `index.html` directament al navegador. Per servir-lo localment amb Python:

```bash
python -m http.server 8000
```

Després obre [http://localhost:8000](http://localhost:8000).

## 🗂️ Estructura

```text
.
├── index.html

├── css/
```

## 🌐 Publicar a Firebase

Amb Firebase CLI instal·lat i el projecte Firebase seleccionat, desplega'l amb:

```bash
firebase deploy --only hosting
```
